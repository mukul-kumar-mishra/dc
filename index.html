How hosting works Open kirvyn.com

Paid micro-clubs, capped at sixteen members.

Hosts set a per-seat price and run chat, events and live audio/video rooms in one place. Members pay by UPI before entry; seats confirm on payment and receipts arrive by email.

Capacity16 seats max per club. Small groups stay conversational; every seat is paid.
Everything in one placeChat, events and live rooms — no juggling three apps. Chat retained 90 days, then auto-deleted.
Money firstUPI seat payments before entry. DestroCorp never sees or stores payment credentials.
DiscoveryMembers find clubs by city across India. Location used only for discovery, with consent.

What a finding looks like Open auditscan.sh

Static code audits with file-and-line findings.

Point AuditScan at a folder or git URL. Every finding cites the exact file and line with fix guidance; a rescan check, PR merge gate and triage board close the loop before you merge.

InputA folder or a git URL. Code is read, never executed.
EvidenceEach finding cites file:line with an explanation of the issue.
ProofRescan confirms cited lines are clear — the merge gate passes only then.
ScopeStatic analysis, not certification and not a substitute for manual review.

Pricing and product details

Frequently asked questions

Contact the team at support@destrocorp.com.

What is DestroCorp?

DestroCorp is an independent product studio in India. It builds Kirvyn community clubs and AuditScan code-audit tools, and publishes Buildopsy, a systems-design journal with courses.

Which product should I start with?

For communities, see Kirvyn. For code review, see AuditScan. For systems-design reading and courses, see Buildopsy.

How do payments work?

Payments are processed by our payment processor. We do not store card or UPI credentials. Digital access is granted after payment; eligible refunds go to the original payment source within 5–7 business days.

How do I exercise my privacy rights?

Email grievance@destrocorp.com or use the data-rights form. We honour access, correction, erasure and consent-withdrawal requests under India's DPDP Act, the EU/UK GDPR, CCPA/CPRA, LGPD, PIPEDA and Australia's Privacy Act.

Do you sell data or run ads?

No. We do not sell personal data, run third-party advertising, or use cross-site trackers on this site. Analytics, if ever enabled, will be first-party and opt-in only.
