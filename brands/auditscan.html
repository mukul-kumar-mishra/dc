AuditScan — catch AI slop, prove every line

By DestroCorp · Live at auditscan.sh · App at app.auditscan.sh. Deterministic static analysis — nothing executes, no LLM decides.

How it works

  • Point at code — a folder or a git URL.
    Nothing executes. Local-path scans are disabled in production.
  • Deterministic sweep — services light up; every finding gets file:line and a counterfactual.
    DEAD handlers, untested risky functions, inputs reaching shell/SQL.
  • Ship proof — PR merge gate, compliance map (SOC2 / ISO 27001 / PCI / HIPAA / GDPR / ASVS / CRA subset), triage board.
    PASS means linked findings are gone on rescan; FAIL stays blocked with exact lines.
Honest scope: AuditScan is deterministic static analysis, not a guarantee of zero vulnerabilities and not a certification. It complements — never replaces — manual security review. Liability is capped to fees paid (see Terms).

Frequently asked questions

Is this PR safe to merge?

The PR Merge Gate rescans a temp copy of the diff. PASS means all linked findings are gone; FAIL stays blocked with the exact lines to fix. No LLM decides.

Does AuditScan certify compliance?

No. It maps the code-verifiable subset of common frameworks and links each control to file:line. Scores are directional — not a certification or legal opinion.

What data do you retain from scans?

Repository file names and scan results, retained until you delete them. Request erasure anytime via grievance@destrocorp.com.
